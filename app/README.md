# 定价参谋工作台

本机运行的 Web 工作台：导入店铺数据，看体检报告、健康度列表和单品建议，记录采纳。产品说明见[上一级的 README](../README.md)。

## 启动

需要 [uv](https://docs.astral.sh/uv/)，Python 3.12 由 uv 自动准备。

```bash
uv sync
uv run advisor                 # 打开 http://127.0.0.1:8321，数据在 data/advisor.db
uv run advisor --db 某个文件.db --port 8322 --no-browser
```

macOS 上也可以双击 `scripts/启动定价参谋.command`。数据存在 `data/advisor.db`，关掉再开还在。

```bash
uv run advisor-backup                            # 备份到 data/backups/定价参谋-年月日-时分秒.db
uv run advisor-restore data/backups/某个备份.db   # 先把当前库另存一份，再用备份恢复
```

## 试一下

1. 启动后点「导入数据」，上传 `samples/样例店/` 里的商品表、销售日记录、竞品价格。
2. 第一次导入会先让你确认店铺参数（扣点率、履约费、退货损耗等），保存后进入体检报告。
3. 到「总览」看健康度列表，点商品名进单品页，拖滑块试算，点「采纳」或「忽略」。

`samples/变体/` 是各种坏文件（缺列、日期格式错、编号重复、售价为 0、非模板）和列名不同、规模较大的样例，用来试导入校验。`samples/反例集/` 是六类容易算错的情形。全部是虚构数据。

## 导入模板

| 表 | 列 |
|-|-|
| 商品表 | 商品编号、商品名称、类目、上架日期、当前售价、成本价、库存数量、生命周期标记（可空） |
| 销售日记录 | 商品编号、日期、当日售价、成交件数、成交金额、退款件数、访客数、广告花费、广告成交件数（后四列可空） |
| 竞品价格（可选） | 商品编号、竞品序号、竞品售价、录入日期 |

表里不要有店名、买家信息。列名和模板不同没关系，上传时确认一次对应关系，之后同样的列名不再询问。缺成本价的商品照常导入，标「数据不足」，可以在页面上补录。

## 参数

默认值在 `config/params.default.json`，代码里不硬编码数值。扣点率、履约费、退货率、最低毛利率、目标清仓天数、滞销线和类目弹性可以在「设置」页改；单个商品的参数可以在单品页的输入面板单独改。改动后只重算受影响的商品。

## 测试与自检

```bash
uv run pytest -q                        # 单元测试与回归
uv run python scripts/accept.py         # 按规格逐条自检，输出「条目、通过、实测」三列
uv run python scripts/smoke.py          # 冒烟：空库 → 导入 → 体检 → 列表 → 单品 → 采纳一条
uv run python scripts/make_samples.py   # 重新生成样例店与变体
```

自检和冒烟都用临时数据库，不碰 `data/advisor.db`。自检里标「人工」的条目需要真实店铺数据或肉眼确认，机器判不了。

## 目录

| 位置 | 内容 |
|-|-|
| advisor/calc.py | 基础量（纯函数）：保本价、毛利率、日均、库存天数、生命周期、数据不足、改价事件、活动日、事件弹性与类目校准 |
| advisor/model.py | 建议（纯函数）：候选价、生命周期目标、库存约束、竞品裁剪、建议区间、健康度、置信度、预估对比、解释四句 |
| advisor/importer.py | 三张 CSV 的表头识别、列名映射、逐行校验、覆盖写入 |
| advisor/params.py | 参数：默认值加设置页的改动 |
| advisor/service.py | 导入编排、整批事务、重算与建议状态、采纳与忽略、各种导出 |
| advisor/main.py | 页面路由 |
| advisor/tools.py | 备份与恢复命令 |
| config/ | 参数默认值 |
| samples/ | 样例店、变体文件、反例集 |
| scripts/ | 自检、冒烟、样例生成、双击启动 |
| docs/ | [技术方案](docs/技术方案.md)、[试用说明](docs/试用说明.md) |

代码注释里的「PRD」「MRD」「验收条例」指项目自己的规格文档；规则编号 R-xx、口径编号 C-xx、步骤编号 PT-xx 出自这些文档，口径补充列在技术方案第 8 节。
