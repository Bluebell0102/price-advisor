# 试用说明（给店主）

> 给试用店主的一页说明。工具装在你自己的电脑上，数据不出这台电脑。**工具不会改你的售价**，改价要你自己到平台后台去改。

| 项目 | 内容 |
|-|-|
| 试用期 | 14 天，从第一次导入起算 |
| 每周要做 | 周一导入一次，约 10 分钟 |
| 怎么打开 | 双击 app/scripts 里的「启动定价参谋.command」，浏览器会打开 http://127.0.0.1:8321；关掉那个黑色窗口就停止 |

## 1 每周一导入一次

1. 从平台后台导出上周的按日按商品成交记录（和第一次导出的是同一张报表），有投放的把推广报表也导出。
2. 打开工具，点右上角「导入数据」，把表拖进「销售日记录」框，点「上传」。商品有上新、改价、改库存时，再把商品表一起传。
3. 表里有错会整批不导，并逐行告诉你哪一行、什么原因，改好再传。同一天的记录重复传会覆盖，不会重复计算。
4. 你在页面上补录过的成本价、手动标的生命周期，下次导入时如果那一格是空的，会沿用你填的值。

## 2 怎么看列表

- 打开「总览」就是健康度列表。**贴近成本**（藏青底）永远排最上面：售价离保本价太近，先看它。
- 其余按「可增毛利 / 14 天」从高到低排。点上面的胶囊只看偏低、偏高等某一档。
- 「数据不足」的商品不给建议：缺成本价的直接在那一行点「补录成本」填上就行。
- 置信度「低」的建议区间是浅色字，意思是你的记录还不够，先小幅试。

## 3 怎么采纳

1. 点商品名进单品页，看「为什么建议这个价」四句话和预估对比；拖价格滑块可以试算任意价。
2. 觉得可以，就在页面底部填采纳价（默认是最优建议价），点「采纳」。低于最低建议价的价填不进去，因为那已经在亏钱的边上。
3. 不同意就点「忽略」，选一个原因。忽略后 7 天内同方向的建议不再提示。
4. 采纳只是记下来：**请你自己到平台后台把价改掉**。工具没有、也不会有「一键改价」。

## 4 试用结束时

- 在「体检报告」页点「导出门 1 评估」，把文件发给帮你装工具的人。它会算采纳率，以及每个采纳过的商品改价前后 14 天的毛利率，和一个没采纳的同类商品对比。
- 想留底就在终端里执行 uv run advisor-backup，会得到一个带日期的备份文件。

有问题找帮你装工具的人，不要自己改数据库文件。
